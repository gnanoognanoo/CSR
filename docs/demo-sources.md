# Project prototype content

These 21 records are original sample concepts for the Projects interface. They are not official CSR-RIT projects, completed implementations, reported results, or assigned work. All records have `isDemo: true`, a `DEMO CONCEPT` status, unassigned demo contributors, and no fabricated repository or live-demo link.

All preview SVGs in `public/projects/demo` are original diagrams created for this prototype. They contain a visible DEMO ONLY label. Values, screens, messages, maps and schedules inside them are fictional. No source photographs, source text, or logos were copied.

The sources below inspired general engineering techniques. Each record links to its primary technical source. Sources were reviewed on 1 October 2026.
